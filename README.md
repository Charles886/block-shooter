# 方塊射擊 Block Shooter

純 HTML5 Canvas 射擊遊戲,用方塊做的測試原型。無任何依賴,開啟 `index.html` 即玩。

## 玩法

| 操作 | 說明 |
|---|---|
| 滑鼠移動 | 操控藍色方塊 |
| 點擊 / 長按 | 朝滑鼠方向射擊 |
| WASD | 額外微調移動 |
| **空白鍵** | 暫停 / 繼續 |

擊殺紅色敵方方塊得分,撐過波次;敵方會追擊並開火。

## 功能

- **波次制** — 敵人數量、血量、速度逐波提升
- **連擊倍率** — 連續擊殺提升分數(最高 x20),受擊重置
- **隨機武器掉落** — 擊殺敵人有機率掉落,撿取後 8 秒生效:
  - 🟢 急速(射速翻倍) / 🟡 三連(三向發射) / 🟣 穿透(子彈穿透) / 🔴 重擊(傷害翻倍)
- **High Score 排行榜** — 結束時輸入名字,存 `localStorage`,前 10 名
- **暫停** — 空白鍵切換,畫面顯示遮罩

## 檔案

```
index.html   介面 / HUD / 排行榜與名字輸入
game.js      全部遊戲邏輯(canvas 渲染、物理、碰撞、武器)
```
